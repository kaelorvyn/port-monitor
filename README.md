# 端口监控

把本机 **65536 个端口**的占用情况画成一张实时地图 —— 哪个端口有程序在监听、哪些是被临时占用的、哪些空着，一屏看完。

**解压即用，不需要安装 Node / Python 等任何东西**：服务端用 Windows 自带的 PowerShell 实现，页面用系统浏览器打开。

---

## 下载

到 [**Releases**](../../releases/latest) 下载 `port-monitor-v1.0.0.zip`，解压后**双击 `启动.cmd`**，浏览器会自动打开监控页面。

关掉那个黑色窗口即停止监控。

---

## 效果

每个小方块 = 一个端口，从 0 排到 65535，一行一行往下排。

| 颜色 | 含义 |
|---|---|
| 🔵 蓝色 | **监听中** —— 有程序在提供服务（这是真正需要关心的） |
| 🟠 橙色 | **连接占用** —— 本机连出去的临时端口，用完就释放，所以会不停闪动 |
| ⚪ 灰色 | **空闲** |

- 鼠标停在方块上会弹出：端口号、占用它的进程、协议和状态
- 窗口下方表格列出所有**正在监听**的端口，带进程名
- 左上角实时显示：监听中 / 连接占用 / 空闲 的数量
- 页面**每 1 秒自动刷新**，不用手动刷
- 左侧一列是端口号刻度，每 8 行标一个，方便定位
- 窗口调宽调窄时格子尺寸自动保持在 12 像素左右，不会变得看不清

### 点蓝色端口直接打开那个服务

对着蓝色（TCP 正在监听）的方块点一下，新标签页会打开 `http://127.0.0.1:端口号/`，鼠标移上去指针会变成小手。

下方表格的「端口」列也是链接，支持右键新标签页打开、复制链接等浏览器原生操作。

- 只有蓝色能点：橙色是本机连出去的临时端口，UDP 端口上也没有网页
- 少数服务跑的是 https，或者根本不是网页（比如 3306 数据库），点开后会连接失败或显示乱码 —— 这是正常的，不是监控坏了

## 顺带科普：端口号怎么看

很多人会被"4 位端口""5 位端口"绕晕。实际上端口号就是 **0 ~ 65535** 之间的一个整数，一共 65536 个，**位数本身没有任何含义**。

真正有意义的是 IANA 划的三段：

| 区间 | 名称 | 谁在用 |
|---|---|---|
| 0 – 1023 | 系统端口 | 操作系统和标准协议（135 RPC、445 SMB…） |
| 1024 – 49151 | 注册端口 | 应用自己挑的（3306 MySQL、8080 开发服务器…） |
| 49152 – 65535 | 动态端口 | 系统自动分配，用完回收 |

地图上能直接看出这条分界线：**从 49152 那一行开始，颜色会突然变密** —— 那里全是临时端口。

## 常见问题

**会被别人从外部连进来吗？**
不会。服务只绑定在本机 `127.0.0.1`，同一局域网的其他电脑也访问不到。

**它联网吗？会不会上传数据？**
不联网。只调用系统自带的 `netstat` 和 `tasklist` 读本机端口，数据不离开本机。

**为什么橙色方块位置老是变？**
那是「临时端口」。你每打开一个网页、每发一条消息，系统都会从 49152 以后随机借一个端口当回信地址，用完就还。

**为什么有些端口显示「（无进程 / TIME_WAIT 残留）」？**
那个连接已经断了，但端口还被系统压着几十秒才会释放，暂时没有属主进程。`netstat` 里这类条目的 PID 是 `0`。

**双击后窗口一闪就没了？**
系统执行策略拦了脚本。右键 `启动.cmd` →「以管理员身份运行」，或先手动开一个管理员 PowerShell，`cd` 到解压目录再执行 `.\启动.cmd`。

**端口 8777 被占了怎么办？**
程序会自动往后找 8778、8779…，黑窗口里会显示实际使用的端口号。

## 实现说明

```
启动.cmd        双击入口，用 Bypass 策略拉起 server.ps1
server.ps1      服务端：TcpListener 手写 HTTP，扫描并聚合端口占用
index.html      页面：Canvas 绘制 65536 格地图 + 1 秒轮询
使用说明.txt     面向使用者的中文说明（随 ZIP 一起分发）
```

几个值得记的点：

- **不依赖 Node**：`TcpListener` 只监听回环地址，不需要管理员权限，也不用注册 URL ACL。
- **画布按设备像素整数绘制**，不用 `ctx.scale(dpr, dpr)` 配小数缩放。在 125% 显示缩放下，后者会让 1px 网格线落在半个物理像素上被抗锯齿糊掉，表现为"有些行没有分隔线"。
- **列数由目标格子尺寸反推**（取 8 的倍数正好摊满可用宽度），而不是写死成 2 的幂 —— 写死的话只能在"太大"和"太小"之间二选一。
- **"已在运行"检测先做本地查询**：`GetActiveTcpListeners()` 瞬时返回，筛出真正在监听的端口再发 HTTP 验证。反过来对 8777–8790 逐个发请求的话，每个没人监听的端口要约 1 秒才失败，启动会被拖慢十几秒。
- **图标是内联 SVG**（data URI），不额外引入文件，也就不用给服务端加静态路由。
- `index.html` **每次请求都重新读盘**，不缓存 —— 否则改完页面必须重启服务端才生效。
